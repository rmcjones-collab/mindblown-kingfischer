# Kingfischer, notes for Claude Code

- The King Brain (`king/king.js`) must stay a pure function: no I/O, no engines, seeded randomness only. All three bots use it unchanged; change rules there and in `docs/KING-RULES.md` together, with a test in `tests/king.test.js`.
- `council/council.js` is engine-agnostic (`makeEngine` is injected). Node-only code goes in `council/node.js`, browser-only code in `bot/browser/`.
- Maia must be read with `PolicyTemperature 1` and `go nodes 1`; castling from Lc0 goes through `standardCastling()`. After changing `bot/browser/maia.js`, run `node tools/validate-maia.mjs` for 1100, 1500 and 1900.
- Never upgrade a Lichess account to BOT, and never commit `LICHESS_TOKEN`. Test with `tools/fake-lichess.mjs`.
- Engines, networks, large browser assets and `kingfischer.config.json` are git-ignored; fetch them with the steps in `docs/SETUP.md`.
- `brains/app.js` and `brains/style.css` are the shared MindBlown renderer, owned by the private `mindblown` repo. Do not edit them here. Facts in brains must be cited; `*-data.js`, `network-data.js` and `brains/*.html` are generated by `brains/build_brains.py`. `brains/import/stockfish-public.json` is the Stockfish brain as published on the AI Hub: do not edit it; add Kingfischer-side pages in `build_brains.py` instead. A page id used in two brains is one shared neuron (same title required), so keep ids distinct unless that is intended.
- Escape data-driven strings before `innerHTML`.
- Don't commit to master. Work on `claude/<topic>`, open a draft PR against a `review-base/*` branch; the owner triggers CodeRabbit (max 3 passes).
- Before a PR: `npm test`, the Maia check, `node tools/build-browser.mjs`, and a browser check of the player. Delete `qa/` afterwards.
- Private repo. The owner decides on previews and publishing. Never publish.
